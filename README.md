# LinuxDo User Tagger (LINUX DO 用户打标与分类工具)

[![Version](https://img.shields.io/badge/version-v0.0.3-brightgreen.svg)](https://github.com/w012w012/LinuxDo-User-Tagger)
[![Platform](https://img.shields.io/badge/platform-LINUX%20DO-blue.svg)](https://linux.do/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](https://opensource.org/licenses/MIT)

专为 [LINUX DO (linux.do)](https://linux.do/) 论坛量身打造的高效用户分类打标、言论溯源与防杠避坑油猴脚本。

> **核心目的**：将日常见到的网友清晰分为【有营养】与【没营养】两类，一眼识别群体特征、回溯历史涉事发言、提前避坑、防冲动回帖，大幅降低无效沟通与情绪消耗。

---

## 🌟 核心功能一览

### 1. 🌐 多场景全覆盖与全局常驻入口
- **顶部导航栏常驻入口**：论坛右上角图标区（搜索/通知旁）常驻注入 `🏷️` 原生风格图标按钮，随时一键唤出管理中心，移动端与 PC 端均触手可及；
- **帖子列表页标签预览**：在论坛首页及各版块主题列表（`latest` / `top`）中，楼主标题后直观呈现紧凑型标签徽章。鼠标悬停即刻预览备注、最新言论与出处，无需点进帖子即可提前预警或识别技术大佬；
- **楼层深度集成**：在每个帖子的楼层作者名旁显示标签栏及快捷打标按钮；
- **个人主页打标栏**：无缝适配 `/u/:username` 个人主页头部，随时查看该用户的历史评级并快捷修改；
- **悬停名片支持**：论坛内点击头像唤出的小名片中，同样支持查看与快捷打标。

### 2. 💬 涉事言论自动抓取与楼层精准直达
- **智能言论摘录**：在任意楼层点击打标时，脚本自动提取该楼层正文前 150 字纯文本（智能剔除内部引用块、代码块、系统徽章等噪音，并将 Emoji 图片还原为文字），作为打标当时的“涉事言论”引述；
- **弹窗内自由编辑**：打标弹窗（Popover）提供多行文本框，提取的言论可自由增删修改或清空；
- **精准楼层外链直达**：自动捕获带有精准楼层定位的直达链接（`#post_X`），在数据中心卡片内点击出处链接，直接新标签页跳转定位到该条发言的具体楼层。

### 3. 📜 历史战绩流水与多条记录留痕
- **时间线流水 (`TagRecord`)**：同一用户在不同帖子中多次发表精彩或奇葩言论时，支持多条历史流水记录，留存每次打标的时间戳、出处帖子、关联楼层链接、发言引述与个人备注；
- **零损耗平滑升维**：自动将升级前的旧版备注、出处与标签无缝封装为初代历史战绩，历史数据与 Gist 云同步 100% 保持兼容、零数据丢失；
- **单条历史精准删除**：支持展开历史战绩，对特定历史记录进行单条清理删除。

### 4. 📊 Bento 统计看板与富信息战绩卡片
- **Bento 栅格统计看板**：
  - 👥 **打标总人数** 与 📜 **累计留痕战绩数**；
  - ⚖️ **群体特征健康度分布**：直观展示 🌱 有营养 vs 🚨 没营养 用户的双色动态比例进度条与准确占比；
  - 🏆 **高频常用标签 Top 5**：按使用频次排行的迷你徽章榜。
- **富信息用户战绩卡片**：
  - 用户主页直达、当前生效标签、关联楼层外链、格式化时间戳（`YYYY-MM-DD HH:mm`）、浅灰引用框言论摘要与个人备注；
  - 拥有多条战绩时提供 `▼ 查看历史战绩 (共 N 条)` 折叠时间轴，支持查看完整履历；
  - **多维筛选与全文检索**：支持快速分类过滤（`全部` | `🌱 有营养` | `🚨 没营养`），搜索框支持同时匹配用户名、标签名、备注以及**所有历史涉事言论全文**。

## 📖 操作指南与使用流程

### 1. 如何为用户打标 / 查看标签？
1. **在帖子楼层**：
   - 找到任意发言楼层，用户名右侧会出现 `+ 标签`（若已有标签则显示徽章）；
   - 点击徽章或 `+ 标签` 按钮，唤出打标弹窗（Popover）。
2. **在主题列表页（首页 / 版块页）**：
   - 看到带有标签的楼主，鼠标悬停可查看其标签、备注及最新涉事言论摘要；
   - 点击徽章可直接打开打标弹窗进行修改或补充。
3. **在个人主页（`/u/:username`）**：
   - 打开用户主页，头部个人资料栏右侧有常驻标签栏，可直接点击查看或修改。

### 2. 打标弹窗（Popover）操作说明
- **选择已有标签**：直接点击分类栏下方的彩色预设胶囊标签，支持同时附加多个标签；
- **添加自定义新标签**：点击分类末尾的 `+`，输入名称后回车或确认（自动智能语义匹配对应 Emoji）；
- **编辑言论引言**：在「💬 标记言论与出处引述」输入框中，已自动提取该楼层发言摘要，可根据需要保留或微调；
- **填写备注**：在「📝 备注说明」输入框中，随手记下打标原因（如：技术好、某帖对线、某领域专家等）；
- **保存 / 清空**：点击「💾 保存标记」完成打标；若要取消打标，删除全部标签与输入内容后保存，或直接在卡片中删除。

### 3. 如何进入「标签管理与数据中心」？
- **方式 A（推荐）**：点击论坛**顶部右上角图标栏常驻的 `🏷️` 图标**，直接打开管理中心；
- **方式 B**：点击浏览器右上角油猴扩展图标，在菜单中选择 **`⚙️ 打开标签管理与数据中心`**。

## ☁️ GitHub Gist 云同步配置指南

1. 打开 [GitHub Personal Access Tokens 页面](https://github.com/settings/tokens/new) 创建 Classic Token；
2. **权限配置**：`Note` 填写 `LinuxDo-User-Tagger`，`Scopes` 仅勾选 **`gist`** 即可，点击页面底部生成并复制该 Token（`ghp_xxxx`）；
3. 点击论坛右上角 **`🏷️`** 打开「标签与数据管理中心」；
4. 在云同步设置区域中：
   - **首次备份**：填入 Token，Gist ID 留空，点击 **`🚀 立即上传备份`**，脚本将自动在您的 GitHub 创建私有 Gist 并自动回填 Gist ID；
   - **多端同步**：在另一台电脑/手机上，填入相同的 Token 和 Gist ID，点击 **`📥 从云端拉取合并`** 即可合并数据；
   - 勾选 **`本地修改后自动同步到云端`** 可开启全自动静默备份。

## ❓ 常见问题 FAQ

**Q1：数据保存在哪里？换浏览器会丢吗？**
> 默认保存在当前浏览器的油猴本地存储（`GM_getValue`）中。如果清理浏览器数据可能会丢失，强烈建议在「管理中心」中配置 **GitHub Gist 云同步** 或定期 **导出 JSON 备份**。

**Q2：其他人能看到我对他们的打标或备注吗？**
> **绝对不会**。本脚本为纯前端本地脚本，云同步采用的是您个人 GitHub 账号下的 Private Gist（私有片段），仅持有所配置 Token 的本人可见，论坛其他用户及服务器完全无法感知。

**Q3：支持哪些浏览器和扩展？**
> 支持 Chrome、Edge、Firefox、Safari 等主流浏览器，适配 Tampermonkey（篡改猴）、Violentmonkey（暴力猴）、ScriptCat（脚本猫）等脚本扩展。

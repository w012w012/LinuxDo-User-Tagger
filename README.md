# LinuxDo User Tagger

专为 [LINUX DO (linux.do)](https://linux.do/) 论坛打造的用户分类打标与防杠避坑油猴脚本。

> **核心目的**：将日常见到的网友清晰分为【有营养】与【没营养】两类，一眼识别群体特征、提前避坑、防冲动回帖，降低无效沟通与情绪消耗。

---

## 🌟 核心功能

### 1. 结构化双分类打标系统
- 🌱 **【有营养】分类（清爽绿/蓝配色）**：`💡 技术大佬`、`🧠 逻辑缜密`、`✨ 妙语连珠`、`👍 理性讨论`、`📦 优质资源`
- 🚨 **【没营养】分类（警示红/橙配色）**：`🚫 纯杠精`、`🧩 逻辑感人`、`⚠️ 极端粉`、`🤡 跳梁小丑`
- **自主增删管理**：每个分类支持自主添加新标签与快速管理删除。

新增标签时无需手动输入 Emoji，直接输入文字即可自动识别并赋予贴切图标：

- **`📦`**：资源、网盘、工具、分享、整理、福利、软件、神器
- **`✨`**：妙语、幽默、风趣、文采、神评、金句、乐子
- **`👍`**：理性、客观、中立、温和、善意、热心、靠谱

### 3. 🌐 多场景浏览全覆盖与常驻入口
- **顶部导航栏常驻入口**：在论坛右上角图标区（搜索/通知旁）常驻注入 `🏷️` 图标按钮，一键唤出管理中心，移动端与日常使用极度便捷；
- **帖子列表页标签预览**：在首页及各版块主题列表（`latest` / `top`）楼主标题后直观呈现紧凑型标签徽章，鼠标悬停可查看备注与最新言论，无需点进帖子即可提前避坑或识别技术大佬；
- **个人主页打标栏**：无缝适配 `/u/:username` 个人主页头部，随时查看打标状态或快捷修改。

### 4. 💬 涉事言论自动抓取与楼层精准直达
- **智能言论摘录**：点击楼层内的「打标」时，自动提取该楼层正文摘要（智能剔除内部引用块、代码块与系统徽章干扰，将 Emoji 图片转换为文字）作为出处引言，并在弹窗中支持自由编辑微调；
- **精确楼层直达**：自动捕获带楼层号（`#post_X`）的高精度 URL，管理中心内点击关联帖子链接直接新标签页跳转至该发言楼层。

### 5. 📜 历史战绩流水与多条记录留痕
- 同一用户在多个帖子中被打标时，自动保留时间线流水（`TagRecord`）；
- 具备**零损耗平滑升维机制**：自动将升级前的旧版备注、出处与标签无缝封装为初代历史战绩，历史数据 100% 零丢失。

### 6. 📊 Bento 统计看板与富信息战绩卡片
- **Bento 统计看板**：
  - 👥 **打标总人数** 与 📜 **累计留痕记录数**；
  - ⚖️ **群体特征分布**：直观展示 🌱 有营养 vs 🚨 没营养 用户的双色健康度比例进度条与准确占比；
  - 🏆 **高频常用标签 Top 5**：按使用频次排行的迷你徽章榜。
- **详细战绩卡片**：
  - 展示用户主页直达、当前生效标签、关联帖子直达外链、格式化时间戳、浅灰引用框言论摘要与个人备注；
  - 多条记录时提供 `▼ 查看全部战绩历史` 折叠时间轴，支持对以往历史记录单独点击删除；
  - 顶部支持一键分类过滤（`全部` | `🌱 有营养` | `🚨 没营养`）与全文快速搜索（支持匹配言论、用户名、标签与备注）。

### 7. ⚡ 防冲动回帖警示（Anti-Impulse Warning）
点击被打上【没营养】标签用户的「回复」按钮时，按钮上方自动弹出脉冲闪烁的红色警示条：
> **⚠️ 已标记为【纯杠精 / 跳梁小丑】，理性交流，谨防被坑！**

### 8. ☁️ GitHub Gist 云端跨设备同步
- **完全私密**：基于 GitHub Secret Gist（私有代码片段）存储，仅自己可见；
- **增量合并**：云端拉取时按标签和历史记录时间智能合并，不覆盖本地新建数据；
- **自动备份**：支持开启本地修改后后台自动同步。

### 9. 数据安全与响应式体验
- **多标签页同步**：支持跨标签页实时同步数据，多页面刷帖不冲突；
- **离线备份**：支持本地一键导出 JSON 备份与合并导入；
- **安全与适配**：全量防 XSS 转义、安全协议校验、支持 `Esc` 键快捷退出、完整适配移动端与暗色（Dark Mode）模式。

## ☁️ GitHub 云同步配置指南

1. 打开 [GitHub Token 页面](https://github.com/settings/tokens/new) 生成一个 Classic Token；
2. 权限仅勾选 **`gist`** 即可，生成后复制该 Token（`ghp_xxxx`）；
3. 点击油猴扩展图标 -> **`⚙️ 打开标签管理与数据中心`**；
4. 填入 Token：
   - **首次使用**：点击 **`🚀 立即上传备份`**，将自动创建私有 Gist 并回填 Gist ID；
   - **多设备同步**：在其他设备填入相同 Token 和 Gist ID，点击 **`📥 从云端拉取合并`**；
   - 勾选 **`本地修改后自动同步到云端`** 可开启后台静默自动备份。

## ❓ 常见问题

**Q1：数据保存在哪里？**
> 默认保存在本地浏览器油猴扩展数据库中。配置 GitHub Gist 云同步后，可在多台设备间一键同步漫游。

**Q2：其他人能看到我的打标记录吗？**
> 绝对不会。本脚本为纯本地运行，云同步使用的是你个人 GitHub 账号下的私有 Gist，全网对他人完全不可见。
